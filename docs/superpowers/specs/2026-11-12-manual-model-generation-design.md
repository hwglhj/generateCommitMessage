# 手动切换模型后立即生成

手动打开提交面板的快速模型菜单后，选中任意 API 或 CLI 模型立即为本次勾选的变更生成提交信息，无需再次点击闪电。打开菜单、展开站点、刷新模型列表和关闭菜单不发起生成请求。

沿用 1.0.4 的面板交互：生成期间保留并禁用模型选择，成功关闭主面板及站点子菜单；失败或取消后恢复原面板。手动关闭后不因失败重新弹出。选择当前已激活模型也可生成。

第一次选中模型时，从打开菜单的提交面板上下文获取已勾选变更及原提交文字，之后的失败重试复用该次输入。无提交面板或没有勾选变更时提示原因，不调用服务；模型设置仍可切换。保留生成期间手动编辑提交文字的保护。模型缓存和独立站点刷新不变。

实现复用闪电按钮的请求工厂和 CommitGenerationRequest；手动菜单在第一次有效选择时创建请求并将已有面板交给请求管理。手动菜单与失败菜单分别显示正常标题和失败标题，不复制 Diff 构建或服务调用。

验证包含真实菜单、提交面板上下文及本地 HTTP 服务的入口集成测试，以及既有 API/CLI 重试、键盘鼠标、取消、重复点击、过期选择和模型刷新回归。
