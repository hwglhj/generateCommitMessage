# 重试成功后关闭模型选择面板

用户确认的行为：选择新模型立即重新生成；生成期间和失败后保留原面板，成功后关闭。API 与 CLI 一致，单站点模型刷新仍保持面板打开。

后续 1.0.5 将选中即生成扩展到手动工具栏菜单，见[手动模型生成设计](2026-11-12-manual-model-generation-design.md)。下文记录 1.0.4 的实现和验证。

同一次 `CommitGenerationRequest` 持有一个面板句柄。开始重试时显示生成状态并刷新选项的禁用状态；失败或取消后恢复选择；成功后关闭主面板及站点子菜单。用户主动关闭后，不因失败重新打开。关闭面板不取消已发出的请求，任务取消仍使用原进度条入口。

原生弹窗会在部分模型选择路径中提前关闭，因此仅在失败重试模式拦截鼠标、Enter 和 Space 的模型选择，保留普通工具栏行为。站点刷新继续原地替换列表，当前站点标签随选中新模型更新。

验收覆盖：连续失败复用同一面板、成功关闭根面板和子菜单、API/CLI、鼠标/键盘、防重复请求、取消、手动关闭及站点刷新。
