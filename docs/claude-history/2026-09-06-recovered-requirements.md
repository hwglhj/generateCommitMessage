## 2. 第三方 API 的历史细节

用户直接提出的是“自行配置第三方 API”，并提供了参考截图。此前实现记录及仓库旧文档将它细化为以下交互，可作为恢复原体验的依据：

- CLI / API 模式切换。
- 多个 API 配置的添加、编辑、删除。
- 选择当前激活的配置，并持久化保存。
- 每个配置包含名称、提供商类型、Base URL、API Key、模型。
- 提供商选项包括 OpenAI Compatible、Anthropic、自定义。
- 模型可以手动填写，也有获取模型列表的操作。
- 测试连接，并反馈成功或失败。
- 旧资源及变更日志还记录了“推理模型兼容性”选项。

这些细节的佐证包括 [旧安装指南](../../INSTALL_GUIDE.md#api-模式配置)、[旧版本变更日志](../../CHANGELOG_v2.0.md) 和 `src/main/resources/messages/SubMsgBundle*.properties`。其中提供商覆盖、推理兼容性及模型列表获取是历史实现/文档细化，不能据此宣称所有厂商协议都已验证。

这里的 API 模式是调用模型服务生成提交信息；被取消的 API Search 是搜索项目 REST 接口，两者是不同功能。

## 3. AI Commit 与界面细节

用户批准的 2026-09-04 设计记录了：

- 7 种 CLI、可输入/搜索的模型框、按 CLI 动态显示思考等级、刷新和测试按钮。
- 6 行高的附加提示词文本框，支持滚动和换行。
- 查看内置提示词使用只读弹窗；清空按钮直接清空附加提示词。
- 默认选中近期提交风格参考，使用最近 10 条提交。
- Diff 最大长度默认 5000 字符，界面建议范围为 1000 到 10000；该建议不等于硬性上下限。
- 输出语言默认中文，可选英文。
- CLI Tools 包含 7 个图标开关和 7 个高权限启动开关。
- 面板内边距及主要垂直间距 10px、标签与输入间距 6px、按钮间距 8px，遵循 IDEA 界面习惯。
- 配置支持保存、重置、修改状态检测；刷新和测试有状态反馈。

AI Commit 中使用名称 Gemini/agy，侧栏中的对应名称为 Antigravity；历史代码和设计存在这两种命名。
